## 什么是大语言模型？

大语言模型是一类基于深度学习的自然语言处理模型，它们能够理解和生成人类语言。这些模型通过在海量文本数据上进行预训练，学习到了丰富的语言知识和世界知识。

### LLM 的核心特点

- **规模庞大**：通常包含数十亿到数千亿参数
- **通用性强**：能够处理多种自然语言任务
- **涌现能力**：展现出令人惊讶的推理和生成能力
- **零样本学习**：可以在没有特定训练的情况下完成新任务

## Transformer 架构

现代大语言模型大多基于 Transformer 架构。让我用一个简单的示例来展示如何使用 PyTorch 实现一个基本的 Transformer 块：

```python
import torch
import torch.nn as nn
import math

class TransformerBlock(nn.Module):
    def __init__(self, embed_dim, num_heads, ff_dim, dropout=0.1):
        super().__init__()
        self.attention = nn.MultiheadAttention(embed_dim, num_heads, dropout=dropout)
        self.norm1 = nn.LayerNorm(embed_dim)
        self.norm2 = nn.LayerNorm(embed_dim)
        self.ffn = nn.Sequential(
            nn.Linear(embed_dim, ff_dim),
            nn.ReLU(),
            nn.Linear(ff_dim, embed_dim),
        )
        self.dropout = nn.Dropout(dropout)

    def forward(self, x):
        # 自注意力机制
        attn_output, _ = self.attention(x, x, x)
        x = self.norm1(x + self.dropout(attn_output))

        # 前馈网络
        ffn_output = self.ffn(x)
        x = self.norm2(x + self.dropout(ffn_output))

        return x
```

## Tokenization 分词

一个我一上来就搞错的事：中文分词。

大多数人以为 LLM 按「词」或「字」切分。英文里确实切词（`transformer` 和 `attention` 分开），
但中文没有空格，模型得自己决定切在哪。你要是直接按空格切，
一整句中文会变成一个 token——注意力预算全浪费了，上下文开销也跟着翻倍。

GPT-4 之后中英文各有对应的 tiktoken 编码（`cl100k_base`、`o200k_base`），
CJK 单字一般占 1~2 个 token。长上下文场景必须用它们，不能自己乱切。

用得最多的其实就两类：把非结构化的东西变成结构化的，以及在已有上下文里做判断。

## 常见问题与解决方案

### Q1: 怎么让输出稳定一点？

先纠正一个普遍的误解：**temperature 调到 0 不保证确定性**。
temperature 只是缩放 logits 的分布，即使缩到 0，浮点累加顺序、批处理时的
kernel 选择、MoE 路由都可能带来微小差异；加上服务端为了吞吐会做连续批处理，
同一批请求的计算路径本身就不同。

想要真正可复现，得同时做到：固定 seed + 固定模型版本 + 关掉连续批处理（大部分厂商不给你这个开关）。
工程上更靠谱的做法是接受不确定性，用缓存和校验兜底，而不是追求位级一致。

### Q2: temperature 怎么选？

经验值：结构化抽取、代码、分类用 0~0.2；文案、创意用 0.7~0.9。
另外注意 temperature 和 top_p 不要同时调，两个都在控制同一件事，互相抵消很难排查。

## 总结

真正决定效果的往往不是「模型有多强」，而是喂进去的东西干不干净、提示清不清楚。
模型微调在大部分场景下性价比不高，改提示和改检索的收益大得多。
